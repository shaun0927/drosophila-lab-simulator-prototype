# Codex Collaboration Note

## R-series update

The notes below describe the earlier competition prototype. The R-series direction has changed: real fly-lab procedure is now the gameplay substrate, while publication satire remains as wrapper, evaluator, and tone. The implementation contract is [`fly-lab-product-thesis.md`](fly-lab-product-thesis.md).

## What Codex/Hermes helped implement

- Competition-scope design document for the 5-minute vertical slice.
- Paper-loop design for Trait → Discovery → Assay → Figure → Reviewer → Result.
- Unity project scaffold and WebGL build script.
- Prototype UI and game-state logic.
- Trait, phenomenon, assay, figure-framing, reviewer, and ending tables.
- WebGL build troubleshooting, including installing WebGL support for the local Unity editor.
- Browser smoke verification via local HTTP server and screenshot inspection.

## Human direction / design judgment

- The core personal premise came from Junghwan's Drosophila/neuroscience background.
- Junghwan rejected procedure-only simulator loops as motivationally weak.
- The design direction shifted toward discovering absurd fly behaviors and selling them as publishable figures.
- The core tension was fixed as: weird enough to be exciting, credible enough to survive review.

## Why this counts as collaboration

The AI system accelerated implementation, documentation, build setup, and iteration. The distinctive design axis came from human domain experience and repeated critique of what would or would not be fun.
