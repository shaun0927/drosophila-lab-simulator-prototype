# 200 Loop Enhancement Report

## What changed

The 200 loop candidates are no longer just generated names plus three generic choices. Each candidate now includes:

- motivation axis
- concrete mechanic
- 30-second pitch
- player promise
- design rule
- prototype focus
- 3-beat structure
- success signal
- cut risk
- choice motivation tags
- choice payoff descriptions

The runner now presents each idea as a small 3-beat playable test:

1. Hook / promise
2. First strategic choice
3. Consequence-shaping choice
4. Result verdict

## Why this helps

This makes the list useful for selection instead of just brainstorming. Each candidate asks a clear question:

> What psychological motive is this loop supposed to trigger, and did it actually trigger it?

## How to use it

For each candidate, ignore polish and score:

- curiosity
- agency
- competence
- tension
- payoff
- replay desire
- presentation clarity

Cut candidates where the theme is good but the result does not create a desire to replay.

Pick 20 by title/hook, then play those 20 and keep 5.
