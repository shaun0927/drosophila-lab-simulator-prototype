# Commercial Reference Method

## Purpose

Junghwan asked that the 200 ideas be refined using successful commercial games, between stage 0 and stage 1.

Each candidate now contains a **Commercial reference mix**:

- primary reference
- secondary reference
- mechanism borrowed from each
- combined design lesson
- adaptation to Drosophila/fly-lab game
- prototype must-show checklist

- Papers, Please [1]

- Factorio [4]

- Strange Horticulture [11]

## How to use

For each idea, check whether the commercial reference mechanisms actually help the 5-minute loop.

Example:

- Strange Horticulture contributes clue-driven expert identification.
- Ace Attorney contributes contradiction discovery and evidence presentation.
- A fly-lab detective idea should therefore show a clue, a wrong interpretation, and an evidence turnabout within five minutes.

If the borrowed mechanism is only a vibe, cut or redesign the idea.

## 0/1-stage question

For each candidate, ask:

> Does the commercial mechanism create an actual playable choice in the first 60 seconds, or is it just a thematic comparison?

Only candidates with a real playable mechanism should move to bespoke prototyping.
