# 200 Idea Divergence Audit

## Audit result

The previous 200-candidate set was **not ideation-ready enough**.

It technically contained 200 entries, but the generation pattern was too grid-like:

- 20 axes × 10 variants
- only 110 unique names
- repeated verb/object patterns
- many candidates felt like permutations rather than genuinely different design prompts

This was useful as a stress test for the runner, but not good enough for broad ideation.

## Regeneration pass

I regenerated the 200 candidates to be more diverse:

- 25 distinct loop families
- 8 variants per family
- 200 unique names
- each candidate has:
  - motivation axis
  - comparable system reference
  - design rule
  - prototype focus
  - 30-second pitch
  - player promise
  - success signal
  - cut risk
  - 3-beat structure
  - three choices with distinct motivation/payoff
