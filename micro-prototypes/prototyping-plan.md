# Prototyping Strategy After 200-Idea Divergence

## Verdict

The idea pool is now broad enough. The next phase should not add more raw ideas. It should turn the 200 candidates into a **selection funnel** that reveals which fun engines deserve bespoke prototypes.

Current phase:

> divergent ideation board → structured playtest funnel → top 3 bespoke prototypes

## Why not implement all 200 deeply?

The 200 candidates are intentionally lightweight ideation cards. If each one gets bespoke UI and rules, the work explodes before we know which loops are worth it.

The right next step is to make the 200 easier to compare by:

- quickly marking interesting candidates
- scoring motivation dimensions
- filtering by genre/motive
- exporting a shortlist
- deciding which 3 deserve deeper custom prototypes

## Funnel

### Pass 1 — Title/hook scan: 200 → 40

Timebox: 30-45 minutes.

Only read:

- title
- hook
- player promise
- cut risk

Mark anything that creates immediate curiosity. Do not judge feasibility yet.

### Pass 2 — Quick play: 40 → 15

Play each selected idea for 1-2 minutes.

Score:

- Curiosity
- Tension
- Payoff
- Replay
- Feasibility
- Presentation
- Personal fit

Keep candidates that score high on **Curiosity/Tension/Payoff/Replay**, even if rough.

### Pass 3 — Design comparison: 15 → 5

For each remaining candidate, write:

- first 30 seconds
- one screenshot-worthy moment
- one repeat-play reason
- one likely implementation risk

### Pass 4 — Bespoke prototypes: 5 → 3

Build custom prototypes only for the top 5. These should no longer use the generic 3-beat runner.

Examples:

- Reviewer Tower Defense needs a lane/wave UI.
- Data Ghost Detective needs a clue board and trace inspection.
- Optogenetic Rhythm Lab needs timing/audio/visual feedback.
- Lab Bench Overcooked needs logistics timers and stations.
- One-Button Publish Panic needs escalating odds and release tension.

### Pass 5 — Final candidate: 3 → 1

Judge by:

- 3-minute first play
- immediate originality
- stable browser playability
- Codex collaboration story
- presentation/video strength
- ability to become either Web-first submission or Unity expansion

## Prototype tiers

### Tier 0: Ideation card

Current 200. Purpose: scan and mark.

### Tier 1: Generic playable card

Current 3-beat runner. Purpose: compare motive and result.

### Tier 2: Bespoke micro-prototype

Custom UI/rule/feedback for a candidate. Purpose: test real fun.

### Tier 3: Competition vertical slice

One selected loop, polished into a 3-5 minute submission build.

## What was added now

A browser-based selection workbench was added to help the next pass:

- filter 200 candidates
- mark favorites
- score each candidate
- sort by total score
- export shortlist JSON
- open each playable idea directly

Use it to move from 200 to 40, then 15, then 5.
